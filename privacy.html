개인정보처리방침

초안 · 법률 확인 전 · 시행일 [미정]

이 러닝 땅따먹기 앱(이하 '앱')은 런랩(이하 '운영자')이 만든 러닝 앱이에요. 이 문서는 앱이 어떤 정보를 쓰고, 어디에 두고, 어디로 보내는지 알려 드려요.

로그인하지 않으면 모든 기록은 이 폰 안에만 있어요. 지도 공유·순위를 쓰려고 구글로 로그인하면, 아래 적은 것만 운영자 서버에 저장돼요. 달린 길(경로)과 심박 같은 건강 정보는 서버에 남기지 않아요.

1. 앱이 쓰는 정보

  • 달리기 기록: 날짜·시간, 거리, 페이스, 심박, 걸음수(케이던스), 오른 높이, 소모 칼로리
  • 달린 길: 앱으로 기록할 때의 GPS 위치와 시각
  • 게임 기록: 밝힌 길, 내 땅, 랜드마크 도장·점령, 챌린지·메달·배지, 운동 계획
  • 직접 입력한 값: 출생 연도 또는 최대 심박(입력한 경우), 알림·화면 설정, 깃발 한마디(골라 쓰는 문장)
  • 오류 기록: 앱에서 난 오류의 내용과 시각(최근 100건, 폰 안에만)

로그인한 경우에만 추가로: 구글 계정 이메일과 계정 번호, 닉네임, 출생 연도, 동의한 시각, 지도 공유를 켰는지, 숨김 구역(이름·중심 위치·반경). 전화번호·연락처는 받지 않아요.

2. 정보를 얻는 방법

  • Health Connect: 삼성헬스·가민 등이 Health Connect에 넘긴 운동 기록을 허락한 항목만 읽어요. 앱이 Health Connect에 쓰지는 않아요
  • 앱 GPS 기록: '달리기 시작'을 누른 뒤부터 끝낼 때까지 폰의 위치와 걸음 센서를 써요. 화면이 꺼져도 기록하며, 그동안 알림이 떠 있어요
  • 구글 로그인: 설정 → 계정에서 직접 로그인할 때 구글이 이메일과 계정 번호를 넘겨줘요
  • 직접 입력: 가입·설정에서 입력한 값

앱을 설치하기 전의 기록은 가져오지 않아요.

3. 쓰는 목적

  • 능력치·레벨·러너 타입 계산, 기록·구간·최고 기록·리포트 보여 주기
  • 고리(땅)·안개·랜드마크 도장 계산과 지도 표시
  • 로그인한 경우: 가짜 기록 거르기(순간이동·차량 속도·모의 위치), 함께 쓰는 지도의 땅 주인 정하기, 지역 순위, 뺏긴 땅 알림, 크루·크루 채팅·친구(신고·차단 처리 포함), 회원 확인
  • 새 달리기·운동 계획·땅 지키기·기록 켜기 알림
  • 달린 시각의 날씨 표시와 더운 날 페이스 보정

광고, 판매, 맞춤형 광고에는 쓰지 않아요.

4. 운영자 서버에 저장하는 것(로그인한 경우만)

  • 계정: 구글 계정 이메일·계정 번호, 닉네임, 출생 연도, 개인정보·위치정보 동의 시각, 지도 공유 여부
  • 달리기 검사 결과: 달리기마다 시작 시각, 거리, 시간, 통과·거절과 그 이유
  • 달린 길(경로): 달리기가 끝난 뒤 올려서 가짜 기록인지 검사하고 땅 칸을 계산한 즉시 지워요. 저장하지 않아요
  • 땅: 약 25m 칸 번호, 날짜, 그 칸을 감싸며 돈 거리(km)와 지금 칸 주인
  • 랜드마크: 도장·점령한 랜드마크 번호와 날짜, 내 깃발에 고른 한마디
  • 순위: 내 동네(행정동·구·시 이름)별 날짜와 순위, 땅을 뺏긴 날·칸 수(최근 60일만 알려 드려요)
  • 숨김 구역: 직접 정한 이름(10자 이내)·중심 위치·반경(최대 3곳). 남에게 보이지 않아요
  • 크루: 들어간 크루와 들어간 날, 크루 채팅 글(200자 이내)·이모지 반응·자동 소식(크루에 들어옴, 달리기마다 고리·땅·점령 수, 레벨), 내가 한 신고(글 내용 포함)와 차단한 사람
  • 친구: 내 친구 코드, 친구 목록·주고받은 친구 요청, 친구에게 보일 레벨·러너 타입·도감 수, 친구 소식(달린 날짜와 고리·땅·점령 수, 레벨 오름)
  • 심박·걸음수 같은 건강 정보와 기록 상세는 서버로 보내지 않아요

5. 보관 기간과 지우는 방법

  • 폰 안 기록: 직접 지우거나 앱을 지울 때까지. 기록 하나 지우기는 러닝 탭에서 기록을 길게 누르기
  • 서버 정보: 회원 탈퇴할 때까지. 탈퇴하면 계정과 4번의 정보가 모두 바로 지워져요
  • 크루 채팅 글·반응·자동 소식: 30일이 지나면 지워져요. 내 글은 길게 눌러 바로 지울 수 있고, 크루장도 크루 안의 글을 지울 수 있어요
  • 친구 소식: 30일이 지나면 지워져요. 친구 끊기·차단은 친구 화면에서 바로 할 수 있어요
  • 신고 기록: 운영자 확인을 위해 신고된 글 내용과 함께 90일 보관한 뒤 지워요
  • 회원 탈퇴: 설정 → 계정 → 회원 탈퇴(앱을 지웠다면 웹 안내: https://sonheichang-hub.github.io/run-app-info/delete.html)
  • 폰 안 기록 전부 지우기: 폰 설정 → 앱 → (이 앱) → 저장공간 → 데이터 삭제, 또는 앱 삭제
  • 백업 파일: 설정 → 데이터 → 백업 내보내기를 누르면 폰의 '다운로드' 폴더에 파일이 생겨요. 달린 길(위치)이 들어 있으니 남에게 보내지 않도록 주의해 주세요

6. 다른 러너에게 보이는 것(지도 공유를 켠 경우만)

  • 땅은 달리기가 끝난 뒤에 반영돼 달리는 중의 위치는 드러나지 않아요

  • 지도 공유는 설정 → 계정에서 언제든 끌 수 있고, 끄면 내 땅이 남의 지도에서 사라져요
  • 크루원에게(지도 공유와 별개): 닉네임, 크루 안 땅 넓이, 크루 채팅 글·반응, 자동 소식(크루에 들어옴, 달리기를 한 날짜와 고리·땅·점령 수, 레벨). 달린 장소와 시각은 보이지 않아요. 자동 소식은 채팅창 메뉴에서 끌 수 있어요

  • 크루 채팅에서는 전화번호·메일·동/호수·아파트 이름·링크가 자동으로 가려지고, 금지된 말은 보낼 수 없어요. 그래도 사는 곳이 드러나는 글은 쓰지 말아 주세요
